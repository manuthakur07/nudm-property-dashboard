# NUDM Intern Assessment 2025 — Manu Thakur

## Overview
This project is a Property Tax Analytics Dashboard built using React.

Features:
- KPI Cards
- City-wise analytics
- Charts & Visualization
- AI Assistant
- Responsive Dashboard UI

## Tech Stack
- React.js
- Tailwind CSS
- Recharts
- JavaScript

## Setup Instructions

1. Clone repository

git clone https://github.com/manuthakur07/nudm-property-dashboard.git

2. Install dependencies

npm install

3. Start project

npm start

## Dataset
The project uses `properties.json` for property analytics data.
