# NUDM Property Tax Analytics Dashboard

## Overview
This project is a Property Tax Analytics Dashboard built using React.js for the NUDM Intern Assessment 2026.

The dashboard displays:
- KPI Cards
- Tenant Filter
- City Wise Collection Chart
- AI Chat Assistant using Gemini API

---

## Features

### KPI Dashboard
- Total Properties
- Approved Properties
- Rejected Properties
- Total Collection

### Tenant Filter
Filter dashboard data city-wise.

### Charts
Bar chart showing collection comparison across cities.

### AI Assistant
Users can ask questions about the dataset using Gemini AI.

---

## Tech Stack

- React.js
- Tailwind CSS
- Recharts
- Google Gemini API
